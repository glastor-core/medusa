# 📖 Cómo Citar este Proyecto (Citation Guide)

Si utilizas **MEDUSA** en publicaciones académicas, especificaciones técnicas, benchmarks o proyectos de software corporativo, por favor cita este repositorio utilizando el estándar **CFF (Citation File Format)** nativo de GitHub o los siguientes formatos.

GitHub renderiza automáticamente el botón **"Cite this repository"** en la barra lateral derecha a partir del archivo [CITATION.cff](CITATION.cff).

---

## Formato BibTeX

```bibtex
@software{medusa_2026,
  author = {Glastor},
  title = {MEDUSA: Enterprise-grade software repository adhering to GitHub 2026 standards and DevSecOps architecture.},
  year = {2026},
  url = {https://github.com/glastor-core/medusa},
  license = {Apache-2.0}
}
```

## Formato APA (7ª edición)

> Glastor. (2026). *MEDUSA* (Versión 1.0.0) [Software de computación]. https://github.com/glastor-core/medusa

## Formato IEEE

> Glastor, "MEDUSA," 2026. [En línea]. Disponible en: https://github.com/glastor-core/medusa.
